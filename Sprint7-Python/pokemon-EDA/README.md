# Pokemon EDA

## How to Run
### 1. Locally on VS Code
 - This project includes a ```requirements.txt``` use it to create a virtual environment
and install the needed dependencies.
 - Install the Jupyter extension by Microsoft to help decide the Kernel (you should be able to choose your virtual env as the Kernel)

### 2. [Jupyter Lite](https://jupyter.org/try-jupyter/lab/index.html?path=notebooks%2FIntro.ipynb)
Lightweight browser solution for running Jupyter Notebooks, all you need to do is
upload the ```Pokemon.csv``` and the notebook file on the same folder level and you can start running your code.
